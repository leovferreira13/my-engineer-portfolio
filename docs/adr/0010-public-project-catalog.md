## Context

Supersedes ADR 0007. Only sports-data-visualizer currently represents public portfolio work; the old personal-site and Smart Scout entries are not the requested catalog.

## Decision

**Use a growing curated project catalog with stable IDs, real live and repository links, a summary, implementation context, technologies, and an optional screenshot.** Start with Football, Visualized only. Reuse catalog data across profile, projects page, journal associations, and text exports.

## Options considered

Keeping placeholder projects would imply public evidence that is not available. A CMS adds operating cost without solving a current need. A typed source catalog is adequate at this scale.

## Consequences

Future public projects are data additions. Keep IDs stable after journal links exist; an editorial move to a CMS would trigger reconsideration.
