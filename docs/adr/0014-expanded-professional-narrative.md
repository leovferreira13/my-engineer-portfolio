## Context

The portfolio has room to explain experience beyond the one-page CV. Product Engineer remains the main positioning, while the same evidence should support Forward Deployed Engineering, Applied AI, and Backend Engineering opportunities. Five language versions and English machine exports must describe the same work.

## Decision

**Expand the existing About, experience, capabilities, and project sections around a single Product Engineer narrative.** About uses descriptive subsections for customer workflows, backend foundations, and applied AI. Capability groups include curated explanations of how tools are used, with equivalent descriptions in all five dictionaries and in English machine exports. Keep the existing section order and card system.

Describe FDE as an adjacent direction supported by customer discovery and integration work, without inventing an employment title. Distinguish platform results from agent results: the appointment agent is in prelaunch testing, and its approximate two-second median voice latency is an internal test result. Preserve the scope of churn indicators, operation-time reductions, and peak capacity.

## Options considered

- **One narrative with concrete examples (chosen):** supports different hiring audiences while keeping a clear identity.
- Separate role-specific portfolio modes: duplicates content and makes the primary story less clear.
- A longer list of tools and titles: adds keywords without explaining practical experience.

## Consequences

The page is longer but uses subheadings and expandable experience for scanning. Copy updates require equivalent language changes; public machine exports reuse the English profile and capability explanations. Revisit the positioning when published work or actual responsibilities change, and update agent outcome claims only when supported by new evidence.
